# R0 电路与机械评审

这些是接线设计及其依据。ERC 检查不检查模拟性能、额定值、协议时序、封装尺寸或密码安全。

## 主电路

| 部分 | 设计与关键限制 |
|---|---|
| MCU | STM32U585RIT6、LQFP64；HSI48/CRS USB 时钟；所有 VDD/VSS/VDDUSB/VDDA 接入、近端去耦；非 Q 型 VCAP 4.7µF，不给外设供电 |
| 主控引脚 | 真实 64 脚表；该封装没有 PB11。PC2 用 SPI2 MISO AF5，PB14 用 I2C2 SDA AF4；表见 pinout.csv |
| 安全元件 | SE050E2HQ1/Z01Z3Z，VIN=3.3V，ENA 默认低；VOUT 仅接本地 VCC/电容，与主 3.3V 分离的 Deep Power Down 接法；ISO7816 与 SE 自身 NFC 接口按未使用规则处理 |
| USB 数据 | TS3USB30EDGSR，0=A / 1=C，`/OE` 上拉，复位时断开数据。每口 USBLC6-2SC6，CC1/CC2 各自 5.1k Rd 与独立 TVS。软件拔插/切换必须撤销授权与端点状态 |
| 双口电源 | 每口输入保险丝/TVS；TPS2116 防倒灌 OR-ing，A 优先，MODE 接 A，PR1=300k/100k 分压。标称 4.0V 阈值，必须计入 0.92–1.08V 基准及电阻公差 |
| 端口检测 | 2N7002 栅极检测原始 VBUS，源极地、漏极 3.3V 上拉，避免把 5V 直接引入断电 MCU。各 VBUS 1M 放电电阻；该检测不是隔离器 |
| 电池/充电 | BQ24074 电源路径；保护板与 10k NTC 内置于 1S 200mAh 电池包。ISET=8.87k，约100mA，必须以电芯规格和最差热条件验证；CE 默认由 SYS 上拉禁充、Q3 开漏授权后开启，关机也不自动充电 |
| USB 电流 | 默认 EN1/EN2 下拉为100mA。500mA/外限/挂起需设备固件依据当前端口的枚举和供电能力控制，不能开机无条件拉大电流。电池可补瞬态电流；总负载尚未量测 |
| 3.3V | TPS63031DSK 固定输出；FB 必须接 VOUT。1.5µH、输入/输出电容按参考设计，实选电感饱和电流/直流偏压/瞬态/纹波待验证；转换器开关噪声不作为侧信道防护手段 |
| 加密存储 | W25Q64JVSSIQ，8MiB；WP/HOLD 上拉。新存储层需 AEAD、唯一 nonce、受保护版本根、掉电事务与磨损策略；当前没有这些设备实现 |
| RTC | RV-3028-C7 自带晶振，VDD=3.3V，VBACKUP=保护电池。不可将主机时间直接作为可信真值；电池故障/时钟标志无效时禁止输出正常验证码 |
| NFC | FM11NC08S，DFN10/EP 待正式封装图核对。VOUT 仅去耦、隔离主电源；芯片内部谐振电容+外部 DNP 调谐位。未设计/调谐实际线圈，不承诺读距或 iPhone 兼容 |
| 用户界面 | I2C OLED、四个机械按键、独立 SPI 指纹接口。指纹接口目前是电气契约，普通明文匹配结果不得授权；模块与显示型号最终选定后复核引脚顺序、包络、供电和逻辑电平 |
| 防拆 | PC13 壳盖触点与 PC0 模块防拆输入；默认锁定/记录异常，去抖；不因接点抖动自动清除全部密钥。简单触点不能抵御探针/开封攻击 |

## 电路检查范围

- 原理图按实际器件脚号连接，所有未用脚显式不连接。库中通用双向 IO 类型仍保留，不为减少 ERC 警告修改电气类型。
- PWR_FLAG 只用于外部电源/地、保险丝后的输入以及已知稳压源经过磁珠/0Ω的派生电源，不替代不存在的供电。
- 自动网表检查验证双 USB 信号与电源未直接短接、SE VOUT/VCC 本地连接、稳压 FB、充电默认禁用接法和关键去耦。它不模拟器件内部行为。
- 8 个封装链接警告对应 J1/J2/J5/J7、U8/U11、SW1/SW6；没有虚构可下单封装。MCU/存储等库封装也须制造复核。

## 机械与 RF

机壳44×88×16mm，USB-A另伸出12mm、按键约突出0.3mm；PCB38×82×1mm。坐标原点为正面左上，USB-A朝Y负方向。四个M2安装位置为(6,6)、(38,6)、(6,60)、(38,60)。孔位与模具尺寸尚未实测。

电池包络20×30×4mm在PCB下；屏幕/指纹位于正面。板底Y≥66mm为RF窗口，不放电池、屏蔽罩、金属螺丝或无关铜。当前PCB规则区禁止该区域全部铜/焊盘/过孔；实现线圈时需针对已测天线单独定义允许层与规则，保留其余层禁布，不能直接删掉整个keepout。

SVG中的三匝轮廓只是分区示意，**不是可加工的天线走线**。最终线圈需测L/Q、13.56MHz谐振、负载调制、ESD与整机iPhone读写。在最终电池/OLED/外壳状态下复测，不能照抄别家线圈尺寸。

壳体是打印样件设计，不承诺防水/IP等级、抗摔等级、屏蔽效能或防拆认证。OLED/可信指纹及USB连接器选型会影响窗口、支柱与公差，量产前需打印并检查所有干涉。
