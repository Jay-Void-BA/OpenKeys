# 三档选择与预算边界

三档均保留指纹独立解锁、设备PIN备用、SE密钥保护、可信屏幕、FIDO/U2F/hmac-secret、TOTP/notes、双USB与NFC。不能把普通明文指纹模块加PIN当作本用户已经同意的降级路线。当前均未达到可生产成品状态。

| 档位 | 指纹/核心 | 取舍 |
|---|---|---|
| 低档研发 | FPC2534AP LGA47 + STM32U585 + SE050E | 指纹公开相关价格¥197.24；材料比flex版低¥49.29/颗。需要另画LGA封装和PCB，贴装/返修可能抵消三把的材料节省；尚未完成这一分支 |
| 中档推荐 | FPC2534AM flex + STM32U585 + SE050E | 指纹公开MOQ1含税价¥246.53，3颗¥739.59。选可拆flex以便调试/维护，配对和持久标签策略仍必须验证；使用单色屏/四层板控制成本 |
| 高档验证 | 先沿用中档实测，再按证据改板 | 费用用于独立功耗/EM/时序/故障注入和EMC评估、返板与复测。更贵MCU或更多层板本身不产生安全等级 |

指纹价格快照：2026-11-08（北京时间），[DigiKey中国](https://www.digikey.cn/zh/products/detail/fingerprint-cards-ab/100026230/25649789)，含13%增值税；库存/价格均须下单前核实。没有代用户锁库存或取得正式报价。

中档3把材料、PCB/小批量装配与外壳可先按¥2100–3600预留询价空间；这是工程预算，额外测试板、完整固件/管理器研发、正式安全评估、认证和返板另列。尚不能以该金额承诺整个定制项目完成。最终以冻结BOM及厂家、开发方、实验室的分项报价为准。

FPC配对标签只有16位：需要SE持久预留且不复用，耗尽后进入设备PIN备用/受控维护；详见[指纹设计](BIOMETRIC_PROTOCOL.md)。这项限制、SE耐久度、模块真实协议行为和整机验证必须在最终选型放行前解决。

完整验收条件、制造渠道与必须由开发方承担的工作见[委托开发任务书](../manufacturing/HANDOFF.md)与[大陆渠道](../hardware/MANUFACTURING.md)。当前图纸和策略测试不能视为成品安全证明。
