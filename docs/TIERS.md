# 低、中、高三档

三档最终功能目标相同；差别在信任链与验证程度。新增 TOTP、notes、recovery codes 后，RTC/电池和加密数据存储重新纳入。低档只是研发原型，不能满足用户对最终强物理攻击防护的要求。

| | 低档功能原型 | 中档目标硬件 | 高档验证交付 |
|---|---|---|---|
| 处理器 | STM32U585，优先易装配 LQFP | STM32U585；按启动/功耗分析比较 H573 | 在中档基础上根据实测决定 H573/STiRoT 或已验证 U585 启动方案 |
| 长期秘密 | 独立 SE050 系列，核对具体 applet/料号；不降为普通 MCU 软件私钥 | SE050，逐项验证 ECDSA/HMAC/对象授权及容量 | 同样 SE 边界；锁定晶圆/芯片修订与评估范围 |
| 指纹 | 普通模块仅供交互研发；真实授权始终要求受保护设备 PIN，不允许其结果单独置 UV | 配对、双向认证、防重放、可信模块固件/模板保护可核对的方案，验证后允许独立指纹解锁 | 评估过的指纹/SE 组合，并实测替换、总线注入和模板提取 |
| 界面/连接 | 单色屏、机械键、A/C 双口互斥、NFC | 同左；最终壳体 NFC 调谐，安全区保护与异常检测 | 同左；按测试结果增强防拆、供电/时钟监测与局部屏蔽 |
| PCB | 四层、安全区完整地、NFC keepout | 四层优先，布局需要才增加层数 | 层数按阻抗/RF/攻击验证决定，六层不是安全认证 |
| 验证 | 功能/负向/断电测试，不宣称抗侧信道通过 | 增加静态审查、模糊测试、基础泄漏与故障预评估 | 第三方功耗/EM/时序/故障注入、EMC、版本冻结复测；FIDO 认证单独申请 |

## 成本：以三把小批量计算

以下是用于比较的工程预算预留，不是现货 BOM 报价，也不含自行开发时间。不能以某金额承诺安全等级。

- 基础硬件连小批量 PCB/代焊，先预留约 ¥300–600/把；新增 RTC、电池、外部加密数据存储、壳体和调试夹具按最终选型另列。返板和多余测试板另列。
- 低档普通指纹模块公开价约 US$19.90–24.90/个，但其匹配真实性/模板保护没有足够证据。这不是可独立解锁 recovery codes 的安全指纹方案。
- 中、高档的安全指纹模组、SDK 许可、3 片供应和安全测试尚无正式报价，因此不能可靠给出完整三把总价。
- ST 官方 STM32U585RIT6 小批量公开价 US$12.10；SE050C2HQ1/Z01SDZ 分销页 US$5.10，但检索时零库存，预计补货不等于交付承诺。SE050E 须核对当前料号/价格，不能用 C 的价格冒充 E 的报价。

价格锚点：[ST](https://estore.st.com/en/stm32u585rit6-cpn.html)、[DigiKey SE050C](https://www.digikey.com/en/products/detail/nxp-usa-inc/SE050C2HQ1-Z01SDZ/10271724)、[普通 UART 指纹](https://www.dfrobot.com/product-2051.html)。

最省钱且保持目标的方法是共用一套核心板、单色屏、取消不需要的无线/钱包/大容量 U 盘，少返板；不要从 SE、可信指纹链路或必要验证上省钱。3 把成品以外，需要额外测试板承担可能破坏器件的故障实验。
