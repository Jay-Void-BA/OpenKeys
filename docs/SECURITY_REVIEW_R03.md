# R0.3 硬件与软件安全复查

日期：2026-11-08（北京时间）。这是本次实现者的自查，**不是独立审计、FIDO/CC/SESIP 认证或“没有所有漏洞”的证明**。对象为本仓库 R0.3 候选电路与当前 Rust 软件；没有实际 PCB/SE/指纹/iPhone 或功耗、EM、故障注入设备。

## 结论

**不批准制造安全成品或存入真实秘密。** 默认软件仍拒绝硬件授权，避免用未实现的驱动模拟成功。当前核心缺口包括完整设备固件、真实认证/计数/存储后端、受保护外设归属配置、完整 PCB 与 RF 设计，以及实机安全证据。没有把这些缺口包装成已验证能力。

## 已发现并处理

| 编号 | 问题/影响 | 本次处理与验证 |
|---|---|---|
| S01 | 旧授权 API 和桌面入口允许 PIN 单独解锁，不符合最新强制指纹要求 | 删除 Method/DevicePin 授权分支和桌面 PIN-only 按钮；Gate 固定先收认证指纹凭据；测试正确 PIN 无法替代指纹 |
| S02 | LCD 查看器原先可只凭 Request 构造，且取消后可能继续提供旧身份帧；集成错误会泄漏私密标识 | 构造必须带私有构造的 VerifiedRequest；取消、超时、时钟回退返回 locked；测试长身份分页、过期/回退及取消 |
| S03 | 异步/阻塞硬件调用后使用旧时间，容易在集成时扩大授权窗口 | Gate 在指纹、PIN、确认和状态检查后读取可信实时单调时间，共用原始期限；慢验证、回退测试拒绝授权 |
| S04 | 只验 GCM、不绑定持久 operation tag 会重放历史指纹结果 | 保留预扣持久失败预算和从不复用 tag；绑定请求/连接/模板/期限；逐位篡改、断电重放、回退、耗尽和持久写不确定测试 |
| H01 | 主电源关闭后，原主电源触点方案不具备防拆留痕供电 | 新增独立3.0V给 VBAT/触点，LSE为备用时钟；网表核对分离供电与PC13。实际备用域配置和测试仍未完成 |
| H02 | 依赖 MCU ADC 才复位不能作为独立降压响应 | 新增独立 UV/OV 开漏复位和 SE 使能互锁；XML检查直接连接。尚无传播/复位/SE停止时序证据 |
| H03 | KiCad TPS3702 库把实际开漏输出标成普通输出，产生错误 ERC 冲突 | 按 TI 引脚表修正为 open_collector；保留原始 ERC 报告，不加忽略规则；现0电气错误 |
| H04 | 把 BQ25185 的4.1V档和100mA输入限流随意组合不符合数据表 | 固定24k=4.2V/100mA，3k设置100mA充电目标；独立网表检查电阻值与引脚 |
| H05 | 输入TVS位于串联保险丝前，持续过压时其分支电流不经过保险丝，可能过热 | 改为F1后接TVS、ESD供电参考和VBUS感知；新增独立网表检查。仍不能替代持续过压切断与热量测，见B12 |

S04 是此前版本已建立的防重放策略，本版复核保留；不表示曾发布过可被此方式利用的实物产品。S01 是新需求下的策略不符；H03 是库模型问题。以上不虚构产品 CVE。


## 尚未解决，阻止安全发布

| 编号 | 风险 | 关闭条件 |
|---|---|---|
| B01 | 不可变启动根存在不代表 GTZC/TrustZone、DMA、调试或更新已配置；保护域被绕过后可滥用 SE | 实机验证启动签名、回滚、错误镜像、调试生命周期、所有主设备/中断/外设归属；独立审核二进制和配置 |
| B02 | FPC 对称密钥双向共用；被攻陷的保护域可能滥用加密服务伪造模块方向帧 | 只暴露有界操作，限制 SE/AEAD API，验证调用路径与权限；对真实 pairing/版本和传感器替换做攻击测试 |
| B03 | SE持久尝试/重试、PIN验证、SCP03、唯一配对密钥和策略对象尚无生产实现 | 在真实 SE 上按写入顺序注入断电、重放和不确定应答；确认无默认密钥、回滚/退款或普通 Flash 计数旁路 |
| B04 | 指纹不是不可复制秘密，传感器防伪/模板保护未经本项目评估 | 固定安全模式、模板与阈值配置，测试仿指、错误率、传感器/排线替换、复位与厂商维护路径；不能用宣传页代替验证 |
| B05 | 16位 tag 共65535次，在频繁失败/取消时耗尽；PIN不能兜底 | 明确每次预扣、寿命和拒绝服务边界；设计经供应商支持与评审的维护/重配对及独立备份，不静默重置 |
| B06 | 独立 UV/OV 有传播/RC/供电窗口，且只观察3.3V；不能挡住所有 VCAP/时钟/EM/激光注入 | 量测3.3V/VCAP/时钟/复位/SE_EN，按扫描范围、重复次数和结果记录攻击；明确残余能力 |
| B07 | 机壳触点可短接；备用电源、LSE、TAMP状态及其完全丢失行为未验证；无经验证主动网格 | 样件测试关机开壳、触点短接/断线、慢/快电源切换、LSE停振与全掉电；丢失连续性时锁定，不重开初始化 |
| B08 | 功耗/EM/时序泄漏与故障触发的密钥泄漏未知 | 对 SE、MCU、指纹和整机电源做范围明确的被动/主动评估；常时软件、屏蔽或 TVLA 阴性都不是不存在攻击的证明 |
| B09 | 认证通道、完整 FIDO、AEAD vault、nonce/版本/掉电事务尚未实现 | 真实驱动、完整状态机、协议负向/互操作与持久化测试；保持默认拒绝直到完成 |
| B10 | NFC芯片EP封装与天线、完整PCB/叠层/回流/ESD夹位/机械配合/实际电池未冻结 | 冻结 BOM/封装与尺寸，完整布局布线、DRC/DFM、最终壳体调谐、热/电池/EMC测试；当前2项ERC封装警告不能忽略 |
| B11 | 桌面构建不等于可用设备管理；NFC手机API不等于已验证管理器 | 三桌面系统+真实设备端到端测试；移动端认证APDU、权限、超时和手机实测；完成签名/公证与安装包 |
| B12 | 尚无独立VBUS持续过压切断；TVS/PPTC不是无限功率稳压或“USB killer”防护，夹位/绝对最大值/熔断时间未验证 | 设计并验证有明确额定范围的输入OVP、EN/CC/数据脚保护及TVS/保险丝协调；量测规定波形和持续错误电源的热/失效模式。只调整TVS位置不足以关闭此项 |


## 已执行的软件检查与边界

Rust 单元/负向测试、畸形输入合成语料、锁屏无私密内容绘制检查；fmt、Clippy `-D warnings`；Cortex-M33 no_std 类型/编译检查；RustSec `--deny warnings`。精确结果见 VALIDATION 和 build-report。依赖扫描只覆盖已知公告，不等于密码实现、驱动或系统库无漏洞。

本项目自己的运行代码禁止 unsafe、不包含 C/C++；第三方 GUI/USB/系统库与芯片 ROM 不在此保证内。没有运行完整覆盖模糊测试、形式化证明、供应链二进制重现或实机侧信道测量。测试中使用的公开合成密钥/数据不是生产密钥。

锁定时公开充电、设备发现和验证指纹所需内部步骤不释放用户私密数据。显示、导出、导入提交与实际签名需新的绑定授权。已获准释放到受感染主机的明文仍会被主机窃取；指纹不能修复主机安全性。
