# R04对抗性复核：当前不能给整机安全背书

日期：2026-11-09。范围：当前R04电路/PCB网表、Rust源码及其明确补丁；不是独立第三方认证，不证明全部漏洞不存在。

**结论：在已实现的软件切片内有可复现的防绕过措施；整机尚不能被确认“理论上不易攻破”，也尚不能正式投入真实账户。** 生产启动/隔离、实际硬件密钥桥接、管理通道和生命周期尚未闭合，物理攻击资格全部NOT_RUN。零ERC/DRC、Rust、安全芯片和CI成功分别证明有限事项，不能组合成未完成的整机安全证明。

## 从真实网表能确认什么

`SE_ENABLE_REQUEST`只连接U4.39与U12.2，U12另一输入来自NRST；U12.4输出SE_EN到U5.11。没有传感器匹配结果的独立硬件证明输入。它是故障/复位使能门，**不是指纹授权门**。必须由受保护启动/内存/外设归属和经过认证的指纹状态机建立真正授权链。

`CASE_CLOSED`连接SW6、U11及U4.2；NRST同时驱动U12与U15，U15.4进入LCD_RESET_N。复位/开盖具有独立电路路径，但触点/连线仍可能被桥接，I2C LCD也没有对显示内容的密码认证。不能据“可信GPIO/有开关”推定对探针、改屏或维护夹具同样可信。

电源有TPS259470L、TPS3702、电池保护和真实NTC的设计；现有OVLO5.5612–5.8436V仅是DC角落计算。eFuse的VBUS保护不能等同USB数据/CC引脚抵抗任意持续过压，ESD器件额定也不是所有注入能量的安全保证。TPS3702约19µs典型响应不能覆盖更快VCAP/FP/SE/时钟/EM故障。网表/布线摘要与独立核对见R04 review，不假定它们验证了这些物理条件。

## 已修正且有软件证据的具体路径

* 主机不能用`uv=false/up=false`绕过设备UV/UP；公共GetInfo去掉私密凭据剩余容量和未开放的主机PIN/config API。
* 私密调用消费不可由主机反序列化/构造的Authorization，绑定操作/实际字节摘要/通道，前后检查时间/状态；授权转移给Root，结束范围即撤销。
* 已批准长事务只获得一次、固定且不可续期的执行范围；不同操作/对象/通道不可借用。FIDO在密码操作前和输出后检查当前授权代际；激活过程中的时钟回退也会在首次密码操作前被拒绝。终端代际耗尽后不再签发授权。
* GetNextAssertion保留原RP、通道、序列和原期限，每个结果需新指纹/确认；U2F不复用缓存触摸。
* I2C仅确认地址阶段忙时可重试；数据阶段NACK、部分收发、时钟回退和晚故障均关闭实例，不自动重发未知完成的SE命令。
* 存储中途掉电/应答丢失不退款nonce，提交锚点坏时不回旧head；流式编辑和范围读取的后段故障会清空前段已复制明文。缓存条目索引也随私密读取故障关闭。
* 逻辑记录排序/数量/长度/命名空间严格核对；notes/recovery另有设备端借用解析器，拒绝错类型、尾随数据、非法UTF8和全部Bidi_Control。主机与设备共享规范编码，不信任主机校验结果。
* SE签名先核对公钥/DER并独立验签；签名计数不回绕、不随notes写入复用，密钥槽先持久预留后生成，未知结果不覆盖或复用。
* 已拦截上游通用FIDO重置，防止先删除共享指纹模板再因持久操作失败而丢失访问。完整Root重置事务未实现时返回不支持，不报告假成功。
* 桌面对话框/后台读取前撤销与遮蔽，选择后重新设备授权；未知焦点、挂起/时钟回退、过期或跨代结果拒绝。宿主/GPU/OS缓存的零化不作绝对保证。

这些测试在公开/合成输入和模型上执行；它们没有把上述OPEN或NOT_RUN改成PASS。芯片已有认证也不自动认证我们的PCB、应用或管理器。下一步由[大陆候选机构](../manufacturing/MAINLAND_SUPPLIERS_AND_LABS.md)先做架构预评估，再按[硬件验收](../manufacturing/HARDWARE_ACCEPTANCE.md)对确定版本开展独立测试。
