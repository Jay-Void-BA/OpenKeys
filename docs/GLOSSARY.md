# 术语速查

[文档导航](README.md) · [当前状态](DEVELOPMENT_STATUS.md) · [架构](ARCHITECTURE.md)

## 先区分这些状态

| 术语 | 在本项目中的含义 |
|---|---|
| 工程候选 | 有可评审的设计 / 源码，仍需集成、首板和验收 |
| 模型测试 | 用可控的输入、介质或寄存器模型验证软件行为；不是实片结果 |
| 电气诊断 | 当前 ARM 镜像用于电气开发，关闭指纹、SE、充电和私密服务 |
| NOT_RUN | 所需测试尚未执行，不是通过 |
| BLOCKED | 缺少生产交付条件 |
| 本项目已确认 | 服务商明确书面接受本项目的个人主体、数量和范围；不是只有服务介绍 |

## 硬件与生产

| 缩写 | 简明说明 |
|---|---|
| PCB / PCBA | 裸电路板 / 装好元件的电路板；都不自动包含机壳和完整固件 |
| BOM / CPL | 元器件清单 / 贴装坐标文件 |
| SMT / THT | 表面贴装 / 通孔插件；LCD、线束等可能另需手工装配 |
| MOQ | 最低订单数量；裸板、装配和元件采购的 MOQ 可能不同 |
| DFM / DFA | 面向制造 / 装配的工程审核 |
| EVT | 首轮工程样板验证，用于发现设计和装配问题 |
| ERC / DRC | 原理图电气规则 / PCB 设计规则检查；不证明整机功能与安全 |
| NTC | 随温度变化的热敏电阻；本项目要求实际贴合电芯 |
| SE | 安全芯片，用于受限密钥和持久状态；芯片认证不自动认证整机 |
| NFC | 近场通信；标准 FIDO 登录与私有管理通道是不同用途，需分别验收 |

## 软件与安全测试

| 缩写或名称 | 简明说明 |
|---|---|
| FIDO2 / WebAuthn / CTAP | 网站认证体系、网页接口及客户端与认证器之间的协议 |
| U2F / CTAP1 | 较早的认证协议；不能从请求中凭空得到网站域名 |
| hmac-secret | FIDO 的按凭据派生秘密扩展；不是动态验证码 |
| UV / UP | 用户身份验证 / 用户在场；本项目另要求设备指纹和实体确认 |
| Root / TCB | 受保护的根执行域 / 必须信任的组件集合；此处 Root 不是桌面的管理员账号 |
| TrustZone / SAU / GTZC | MCU 的安全域及内存 / 外设归属机制；必须配置并验证实际访问 |
| SCP03 | 本项目 MCU 与 SE 之间的认证加密会话，不是电脑与设备的管理协议 |
| APDU | 智能卡式命令 / 响应格式；收到格式正确的包不等于对端可信 |
| AEAD / nonce | 同时保护机密性和完整性的加密 / 每次加密使用的唯一上下文值；仍需另处理旧快照回滚 |
| Execution | 一次批准后仅针对同一请求的固定执行范围，不是通用解锁时段 |
| staging | 在最终提交前暂存和校验一批导入内容的阶段 |
| EMC / ESD | 电磁兼容与抗扰 / 静电放电；不代替抗故意硬件攻击测试 |
| SCA / FI | 侧信道分析 / 故障注入，分别检查泄漏与异常运行能否破坏安全判断 |
| FAR / FRR | 指纹误接受率 / 误拒绝率；几次手指试用不能证明达到声明指标 |
| PAD | 呈现攻击检测，例如假指纹；加密的匹配结果不证明假指纹一定被拒绝 |
| TOE | 认证或评估的对象范围；常规 FIDO 评估可能不包含 notes / recovery codes 和管理器 |
| CI | 自动构建和检查；成功只支持其实际覆盖的提交与范围 |

需要操作步骤时查[开发起步](GETTING_STARTED.md)、[硬件验收](../manufacturing/HARDWARE_ACCEPTANCE.md)或[安全测试计划](SECURITY_TEST_PLAN.md)。
