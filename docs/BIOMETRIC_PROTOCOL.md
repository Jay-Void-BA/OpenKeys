# 指纹独立解锁：FPC2534AM 目标与边界

R0.3 最新要求：设备指纹必须通过，PIN 仅作附加验证，绝不是备用解锁路径。本版把目标从未定模块收敛为Fingerprint Cards **FPC2534AM / 100026230**，采用12pin flex的SPI接口；选型依据为公开产品规范SPC27317 Rev6与安全补充SPC27387 Rev3。它是待实机验证的设计选择，不是整机安全认证。

## 接口与默认状态

见[器件清单](../manufacturing/critical-parts.csv)和当前[R04电路图](../hardware/r04/exports/OpenKeys-schematic.pdf)。CONFIG接地选择SPI，IRQ为高有效，RST_N上电保持低；pin10为3.3V，pin11为信号地，pin12为外壳ESD地。FPC2534AM是带flex的模块，不能拿LGA47的FPC2534AP直接替换。J5为Hirose FH12-12S-0.5SH(55)，0.5mm、底接触、0.3mm厚flex；接触面和引脚1必须通过样件核对。

模块出厂未开启安全通信。成品必须在受控制造条件下生成每台独立AES配对密钥，写入模块并由SE保护主机端使用权限，复位后验证安全模式。禁止采用上游示例密钥，禁止主机/USB端发起重新配对，禁止接受明文识别成功。出厂工厂复位能力保持关闭；模块复位不能清空主控侧的持久失败次数。

## 随机IV不等于防重放

公开协议的安全帧使用AES-GCM，包含8字节AAD帧头、12字节随机IV、16字节认证标签和密文。Identify请求/结果另带**16位operation tag**。只检查GCM认证而忽略请求标签，会把历史有效消息与本次授权混淆。

本项目的有限标签空间策略是：

1. 用户在设备上表达本次操作意图后，SE支持的持久状态先预扣一次生物尝试预算，并为该配对密钥保留一个从未使用的tag。
2. 先确认失败预算预扣持久化，再保留tag并确认持久化，两者都完成后才发送加密Identify请求；允许有序写入，不假定SE支持跨对象原子事务。tag绑定完整操作摘要、连接、目标模板ID及15秒期限；同一时刻只允许一个请求。
3. 只接受来自应用固件的安全帧。检查AAD、完整长度、命令/事件类型、GCM认证、tag、模板ID、匹配结果及操作上下文。普通状态帧不能授权或续期。
4. 接受成功后还需SE持久记录重试状态更新，随后由外层安全域检查屏幕确认。任何失败、取消、拔插或超时都使该次请求失效；已经分配的tag不会退回。
5. 65535次尝试后禁止回绕；该配对停止授权，PIN 不能替代指纹。需要独立备份和受控制造/维护流程；不得静默重配对、重置计数或开放旧秘密。

这使“截获一条尚未送达的成功消息，断电后再送达”也不能复用旧tag。MCU保护域也必须限制配对密钥的加密服务；同一对称密钥同时用于双向通信，密钥不导出本身不能防止已被攻陷的MCU滥用加密服务伪造模块方向消息。前提是SE的预留/失败计数真实抗回滚、配对密钥保密、模块不被替换为可伪造结果的设备，以及主控保护域和确认路径成立。

标签空间在20次尝试/天时约9年、100次/天时约1.8年耗尽；计算包括失败/取消等尝试。这是协议空间上限，**不是**电池、SE耐久度或整机寿命保证。量产方案还须评估能否使用供应商正式支持的安全会话/重新配对机制；不能擅自发明未验证的密钥轮换命令。

## 实现与验证

[biometric.rs](../crates/device-policy/src/biometric.rs)是无堆分配的no_std接收/授权策略。生产代码没有可用的默认GCM或普通内存计数器后端。`ProtectedGcm`和`ProtectedAttempts`必须由真实受保护设备适配器实现；桌面软件仍无法自行解锁设备。

测试使用公开测试密钥、唯一测试nonce与RustCrypto AES-GCM，覆盖全部384个帧位的逐位篡改、截获消息跨复位重放、计数回退/耗尽、持久化不确定、错误模板/请求/连接、超时、阻塞的密码/持久化操作之后再次检查时限，以及状态帧不续期。另通过Cortex-M33目标编译检查。测试不是芯片通信、SE计数器原子性或指纹防伪测试。

**当前实现与尚缺**：SE计数/重试对象APDU、目标SAES-GCM、指纹SPI和加密请求构造已有候选源码；配对/模板/取消运行时、模块固件版本/复位行为核查、持久故障实验、侧信道与故障注入资格、生产FIDO硬件Env与可信UI整合仍未完成。未完成这些之前不能批准指纹独立解锁真实秘密。
