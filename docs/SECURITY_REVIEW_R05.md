# R0.5 安全复查与未关闭事项

[状态](DEVELOPMENT_STATUS.md) · [会话与测试](PIN_SESSIONS_R05.md) · [制作 / 实物测试](../manufacturing/BUILD_R05_ZH.md)

**当前不能确认整机“理论上不易被攻破”。** 生产 Root、可信启动配置、SE 原生权限与 USB / NFC 管理通道未完成，存在足以阻止正式交付的缺口。电路检查、模型和依赖审计不能取代实物攻击评估，也不能保证抵抗所有攻击。

## 已审查的攻击面

| 攻击面 | 当前候选措施 | 尚需证明 |
|---|---|---|
| PIN 猜测 / 掉电返还 | 六位本地十键；完整猜测持久预扣；第 11 次错误锁存擦除，改 PIN 同样锁存 | SE 实片掉电语义、ACL、完整销毁、不重新开放半配置设备 |
| PIN / 协议混淆 | 硬件与六个协议角色独立，30 秒期限和每请求原生权限检查 | 真实库状态接线、FIDO RP / token、OpenPGP / PIV 角色 / 槽验证 |
| NFC 缓存窃用 / 保活 | 绑定配对对端、认证通道、物理场次；保活不续期，离场立即撤权 | 真正握手、可信 RF IRQ / 时间、重连 / 换端 / 重放实测 |
| 确认后权限过期 | 确认前后、执行开始再次检查；一次执行和完成凭据 | 所有生产服务都使用同一 Gate，不存在旁路 APDU / debug / 工厂命令 |
| OTP 泄露 / 重用 | SE 内 HMAC、不读种子、仅设备六位码；HOTP 预增；TOTP 时间检查 | 导入 / 删除、RTC、防回退、密封目录、原始 MAC / calculate-all / 键盘导出均关闭 |
| LCD 残留 / 故障 | 锁存切电与 I2C 隔离、500 ms 关断、泄放、冷启动、失败闭锁 | 实际模块电容、背供电、低温残影、外部注入和供电下限 |
| 电压 / 时钟 / 电磁故障 | 监督器、复位互锁、受限服务、可信时间 / 代际检查的设计 | 更短毛刺、比较跳过、SE 会话 / nonce / 计数 / 启动 / debug 故障注入 |

## 关键结论

1. **SE_EN 不是 PIN 验证器。** 当前 SE PIN 候选依赖可信 MCU Root；已控制 Root 或成功跳过比较分支的攻击者可能绕过策略。必须完成启动、隔离、调试生命周期，并进一步验证 SE 原生认证 / ACL 是否能强制 PIN 后才允许私钥操作。用户要求的独立硬件强制尚未实现。已核对的原生 UserID / 限次接口及必须排除的绕过路径，见[SE 原生 PIN 候选评估](SE_NATIVE_PIN_FEASIBILITY_R05.md)。
2. **六位 PIN 不抵挡离线提取。** 均匀随机组合约 19.9 位；生日、重复数更弱。假设计数不可绕过且完全未知均匀 PIN，11 次猜中概率约 11/1,000,000；该估计不覆盖侧信道、故障、泄露或重试绕过。擦除策略也允许持有设备的人制造拒绝服务。
3. **常数时间和认证芯片不等于整机抗侧信道认证。** PIN 在 GPIO 和 MCU 内仍有暴露；电源 / EM / 总线 / 屏幕可被观察或注入。随机延时和屏蔽不能独立证明安全。
4. **擦除锁存不等于擦除完成。** 当前代码持久阻止正常访问，但尚无删除 SE 所有私钥、OTP、协议 PIN、配对、Flash 密钥 / 目录 / staging 的受控原子流程。不得称为已完成“全清空”。
5. **管理器界面不等于安全管理通道。** 当前 GPUI 后端拒绝真实设备操作，手机 App 未交付；不能把占位按钮或 host Boolean 作为授权。

## 放行前必须关闭

- 可信启动、签名升级、防回滚、生产调试配置、Root / SAU / GTZC / DMA / watchdog、可信时钟与 RTC。
- SE 实片身份 / KAT / 容量 / ACL / 生命周期、唯一随机配对、首次设置和完整擦除掉电恢复；没有公共默认秘密。
- FIDO CTAPHID / NFC、生产 Env、OpenPGP / PIV、SSH 各路径、OTP 导入与显示、加密记录与真实管理通道集成。
- 三桌面与三移动系统的实际构建、权限、认证与断连撤权；iPadOS 不宣称 NFC。
- LCD 电源 / 线束 / 复位、首板 / RF / 温升 / 电池 / EMC / ESD，SCA / FI / 拆机与修复复测。
- 固定提交、CI / 审计无告警、每台样机追溯和独立安全复核。

当前 [R04 对抗性复核](ADVERSARIAL_REVIEW_R04.md)仅用于共用模块历史追溯；其指纹 / 模板 / 四键和旧测试结果不是本版需求或安全结论。
