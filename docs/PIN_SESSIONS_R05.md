# 六位硬件 PIN 与协议 PIN 会话

[架构](ARCHITECTURE.md) · [当前状态](DEVELOPMENT_STATUS.md) · [策略源码](../crates/device-policy/src/session.rs) · [回归测试](../crates/device-policy/src/session_tests.rs)

已确认的规则：**硬件 PIN 和协议 PIN 都可缓存，但分别计时、分别授权，只能用于同一已配对认证会话。** 敏感操作仍需钥匙本地完整请求审阅及新的实体释放确认。

## PIN 的两个层次

硬件 PIN 在首次开机由钥匙十键设置为六位；电脑 / 手机不能提交它。FIDO clientPIN、OpenPGP 用户 / 管理 PIN、PIV PIN / 管理凭证是独立协议凭证。验证硬件 PIN 不设置协议验证标志，验证协议 PIN 不能解锁硬件。

默认协议角色分为 FIDO PIN、OpenPGP Sign / Other / Admin、PIV PIN / Management。缓存不能扩大 FIDO token 的权限 / RP 范围，也不能跨 OpenPGP 密钥用途或 PIV 槽策略。生产 verifier 必须校验**每次规范化请求**的原生权限，不能相信主机传入的“需要哪个 PIN”字段。

## 30 秒规则

| 事件 | 结果 |
|---|---|
| 新的本地六位 PIN 成功并确认配对会话 | 硬件 PIN 租约 30 秒；清除此前协议 PIN 状态 |
| 对应协议 PIN 真正验证成功 | 仅设置该协议角色的 30 秒期限，不续硬件 PIN |
| 完整请求通过设备确认 | 为本次请求发放一次性权限，硬件期限续 30 秒 |
| 私密操作成功、受保护执行器交回不可伪造的完成凭据 | 续硬件期限，并只续本次实际使用的协议角色 |
| USB 供电 / 连接、NFC 场仍在、轮询、保活、失败或取消的请求 | 不续期 |
| 30 秒无有效活动、手动锁定、USB 断连 / 重置 / 挂起、NFC 离场、休眠、硬件 / 时间故障 | 清除硬件及协议状态、失效授权、停止私密显示；撤权不等主机 ACK |
| 新 NFC 场、重新选择应用、重新握手、另一对端、另一通道 | 新会话，不能继承缓存；重新本地 PIN |

Root 在开始新的本地 PIN 输入之前就必须清除旧缓存。输入一半 / 取消不扣错误次数；恰好六位提交后先持久预扣，再比较。中断或丢失应答保守计入已完成尝试，不盲目重试。正确验证可重置失败预算；十次错误后第十一次若正确可以成功，**第十一次完整错误**或其无法判定结果的中断触发持久 ERASE_PENDING。更改硬件 PIN 也先锁存该状态，随后必须销毁全部用户数据、协议 PIN / 配对 / OTP / notes / recovery / 密钥和目录，再受控初始化。当前代码只有擦除锁存，完整销毁服务未实现。

一次经确认的长事务有固定执行预算：通常 15 秒，明确的批量导入 / 密钥管理最多 300 秒。它只能完成原请求，不开放其他操作，不能由传输进度或保活延长。事务结束后才开始新的 30 秒空闲期限；失败 / 超时应锁定。生产 Root 必须检查中途离场和撤权，不能用“长事务”绕过断连锁定。

## NFC 与标准认证的边界

管理通道必须用设备身份、配对公钥、临时密钥与 transcript 建立认证加密会话，包含双向消息序号 / nonce、方向、版本、操作和通道绑定。NFC UID、AID、USB 描述符、RF 在场布尔值都不是对端认证。场次编号只能来自可信射频 / USB 驱动；丢失离场 IRQ 不能继续使用租约。

标准 WebAuthn / CCID 客户端没有管理器配对证明。它们**不能继承管理会话的解锁缓存**；其本地 PIN / UP / UV 流程必须单独设计并验证。为了兼容而把任意 NFC APDU 或 USB 主机视作已配对，会破坏这里的授权边界。当前 session 模块不代表完整管理加密握手或标准认证传输已经实现。

## 必测场景

1. 持续保活超过 30 秒仍锁定；每个协议角色单独到期，查看 notes 不延长 PIV PIN。
2. 在实体确认与执行之间让协议 PIN 过期 / 权限改变：必须拒绝；FIDO 同 PIN 换 RP / 权限也拒绝。
3. 输入中断不扣额度；在每次 SE 预扣 / 比较 / 返还 / 擦除 APDU 边界断电，不能返还失败次数或重置为空白。
4. NFC 离场后快速重入、换手机、复用 UID / 通道、重放旧 transcript / 完成消息：均不能继承缓存。
5. 手动锁定、挂起、时钟回退、篡改、计数耗尽时，所有在途权限和私密 LCD 都撤销。
6. TOTP / HOTP 码仅设备显示；响应、日志、通知、剪贴板、USB 键盘、OATH calculate-all 和明文种子导出均不可出现。

源码测试覆盖状态机和模拟后端。真实加密、SE、USB / NFC IRQ 与定时撤权尚未接入生产 Root，实物结果仍为 NOT_RUN。
