## 工厂确认清单

- [ ] 接受个人和本次数量，并明确最少费用 / 排期 / 报价有效期。
- [ ] 已补齐完整 MPN、容差 / 耐压 / 功率 / 温度参数、采购 MOQ 和损耗；F1 等待定物料已明确。
- [ ] 特殊 SE / NFC / 电源封装、指纹底接触插座与实际物料图纸核对一致；安全关键料不自行替代。
- [ ] 回传 DFM、工程边 / 拼板、钢网开窗和贴装预览；有源单板改动须回项目修订。
- [ ] 机贴后进行 AOI 和关键焊点检查，QFN / EP 的检查方法明确。
- [ ] 首次上电先不装电池，核对 J2.1=BAT+、J2.2=GND 与实物插头极性。
- [ ] 电源 / 故障 / 显示复位按验收表记录波形；不以“亮屏”代替测量。
- [ ] 现有镜像仅为空白 OPEN / TZEN=0 板的电气诊断，不启用指纹、SE、充电、USB / NFC 认证。
- [ ] NFC 装壳调谐和手机实测需相应固件 / 仪器，另列范围。
- [ ] 未接收生产密钥、真实指纹模板、PIN 或恢复码；本单不授权生产个性化、熔丝闭合或付费安全认证。
