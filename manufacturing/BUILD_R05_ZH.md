# R0.5 从材料到三把密钥：工程制作与测试说明

[当前硬件](../hardware/r05/README.md) · [安全复查](../docs/SECURITY_REVIEW_R05.md) · [境内渠道](MAINLAND_COMPONENT_CHANNELS.md) · [工厂 / 实验室筛选](MAINLAND_SUPPLIERS_AND_LABS.md)

**版本已正式变更：无指纹、6 位设备 PIN、0–9 十键、DFR0555 蓝底白字双行 LCD。** 此说明覆盖工程样板的准备和后续放行条件。当前完整认证器仍未完成，诊断固件不能作为三把成品密钥；不要把 R0.4 手册中的指纹、旧 LCD、四键或旧壳体加入新订单。

## 1. 冻结版本和委托范围

先保存 GitHub 的固定提交 SHA，下载 `hardware/r05/` 和 `firmware/r05/`。运行 `python3 hardware/r05/tools/manifest.py --check`；确认 BOM、Gerber、CPL、原理图和 PCB 都属于 R0.5 同一个摘要清单。摘要不是生产签名或安全证书。

给工厂明确写：**个人客户，工程样板，最终需要三把；先做一块装配与试装，不注入任何个人密钥、PIN、恢复码。** 报价分列 PCB / 钢网 / 双面贴装 / THT 后焊 / 自带料 / 工程费 / 结构试装 / 检测与返修。要求确认能否按此数量和个人身份签约付款，不能只看“支持小批量”广告。现有候选及联系状态不等于本项目已被接受。

PCB 商常以 5 块起板，而贴装数量可以另谈；以实际报价为准。若实验室要破坏性测试，应增加独立工程样品，不从三把最终密钥中临时抽取已有真实秘密的设备。

## 3. 下单 PCB

上传 **`hardware/r05/exports/OpenKeys-fabrication.zip`**，不是旧目录的 ZIP。订单目标：四层 FR-4、板厚 1.0mm、无盲埋孔，通孔过孔钻径 0.30mm、外径至少 0.60mm、最小线宽 / 间距 0.15mm；板体 96×112mm、含 USB 舌部包络 96×114.5mm。表面处理、铜厚、阻抗 / 层叠公差和阻焊桥要求应由 DFM 书面确认后冻结；模拟使用 35µm 铜，不允许工厂静默更改层叠后仍沿用 RF 结论。

要求检查：USB 焊盘 / 开槽、SE050 0.4mm pitch 及 EP 钢网、eFuse 复合焊盘、NFC 裸露焊盘、阻焊桥、双面贴装与底面电池净空。J4 是板上铜天线，不是连接器或需要采购的部件。两内层地平面必须按资料在天线区域前停止，不能自动整板铺铜；不要自动加测试铜、铜字、金属件或更改绕组。

普通 Gerber 连通性不证明 USB 信号完整性、NFC 调谐、热可靠性或安全性。要求保留 DFM 修改记录，改版后重新导出并复核，不让工厂私下改网表。

## 4. 委托代焊

同时交给工厂：Gerber / 钻孔 ZIP、[BOM](../hardware/r05/BOM.csv)、[SMD CPL](../hardware/r05/exports/OpenKeys-SMD-position.csv)、[原理图 PDF](../hardware/r05/exports/OpenKeys-schematic.pdf)、[装配尺寸 PDF](../hardware/r05/exports/OpenKeys-dimensions.pdf)。CPL 使用钻孔原点；旋转方向应由工厂贴片预览、引脚 1 标记和本板实际封装共同核对。

要求双面贴装，J1 / J2 / J6 / J7 等连接器、按键、线圈及 THT 后焊分别核实。**J3 调试排针为 DNP，不按普通 BOM 数量焊上；J4 不买不焊。** 后焊不得压迫软包，电池最后接入。关键封装宜 AOI，SE / MCU / NFC / 充电器裸露焊盘及疑似短路部位需要 X-ray / 返修确认。

先索要一块不带电池、不注入秘密的装配样板及测试照片。普通代焊服务不自动包括焊后上电、固件烧录、SE 配置或安全测试，须在报价里明确这些工序。

## 5. LCD、十键和外壳试装

先用万用表识别实际模块丝印及 V1.0 / V1.1。**本板 J7 是自定义 2.54mm 四针内部接口，逻辑顺序为 1=LCD_VCC_SW、2=GND、3=SCL、4=SDA，不能假设与 DFRobot Gravity 插头直接同序同距。** 线束厂须按模块真实丝印转接，做 100% 通断 / 极性核对、绝缘、防反插标记和拉力固定；不把 5V VBUS 接到它。

模块 87×32×13mm 的外形来自厂家规格，背面器件、安装孔及视窗没有假定成完整机械保证。先检查保持架只托绝缘 PCB 边缘，不碰背面焊点 / 器件；使用必要绝缘垫，核实键帽总行程、复位、壳体触点预压和 USB 插拔间隙，再更新结构公差。STL 是候选结构，不可跳过试装直接订三套昂贵模具。

十键排布为 1/2/3、4/5/6、7/8/9、居中 0。每键是独立 GPIO。NFC 绕组在左侧，禁止电池、螺丝、保持架金属或屏蔽片伸入此区。透明片 / 胶水 / 防拆封签不得影响键行程或压住软包。

## 6. 首次上电与诊断

委托熟悉小型安全硬件的工程人员操作限流电源、万用表、示波器和合规 SWD 调试器；你没有这些工具时，要求工厂把此项单独报价。测试时不连接真实账户，不写入个人 PIN / 恢复码。

1. 不上电检查正负极、焊桥、主电源对地阻值和连接器针序；确认没有装上 J3 排针、没有多余外部接口。
2. 按工程供电夹具接入限流电源，先不接软包。避免让实验电源和充电器 / 电池互相灌电；不要直接把调压电源对顶板上稳压器或注入 VCAP。
3. 测 5V 输入、SYS、3.3V、备用 3.0V、独立 VCAP、电流和温度。NC / 未接数据线不能误使能充电或私密操作。
4. 核对实际板号与 LCD 版本，使用 [R0.5 诊断说明](../firmware/r05/README.md)对应镜像。此镜像只测公开 LCD / 十键 / Flash ID，SE、充电、USB/NFC 协议及私密操作均关闭，不测试真实 PIN，不配置熔丝。
5. 十键逐个短按 / 长按，核对数字与固定 MCU 引脚；测试同时按两键、滚键、按住再换场景，不能多出确认。
6. 用示波器测 LCD 供电、NRST、POWER_LATCH、BUS_ENABLE 和 SE_EN。复位 / 开壳 / 异常时应断 LCD 电和两条总线，复位释放后不应自行亮回旧内容。测量并记录真实文字消退，不只看背光。
7. 再接已核实极性的保护电池和真实 NTC，确认无异常热、反灌、压迫。当前诊断不支持充电；生产充电服务完成后才测充电 / 挂起。

任何轨电压、温度、外观或显示行为不符就停电排查，记录原始量测，不以“能显示字”作为整板通过。

## 7. 软件接通后做功能与负向测试

下表的 PIN / FIDO / 机密存储测试需要生产 Root 与真实硬件服务，**当前诊断镜像不能执行**。先完成软件并只写入合成数据；每项留提交、固件摘要、样机编号、仪器和结果。

| 项目 | 测试方式和失败条件 |
|---|---|
| PIN 限次 | 完整六位错误猜测跨每个 SE APDU 边界切电，不得返还额度；半输入取消不扣。第 11 次错误或结果不确定必须锁存全清空；改 PIN 同样清空，不能因半擦除重新开放空白初始化 |
| 会话缓存 | 两种 PIN 分别计时；连续 USB/NFC 保活不续 30 秒；RF 离场 / USB 断连、重连 / 换端、协议 PIN 过期或换 RP / 密钥角色均不得继承旧权限。详见 [PIN 会话](../docs/PIN_SESSIONS_R05.md) |
| OTP / 新协议 | RFC 向量、HOTP 预增 / 丢应答、TOTP 失时 / 回退；种子与六位码均不在主机响应 / 键盘 / 日志中出现。OpenPGP / PIV / SSH 各自 PIN 和签名策略分别验证 |
| 主机拒绝服务 | 无人碰设备时连续请求、断连、重新连接；不得花掉 PIN 次数。正在输入时第二请求不能替换原请求 |
| 请求 / 确认绑定 | 用合成 RP ID、长域名后缀、变更摘要 / 通道、重放旧许可、超时、按住 5 换场景；不得签署未明确审阅的请求 |
| 机密可见性 | PIN 前读取 notes、恢复码、标题、账户、凭据列表和导入预览均拒绝；锁定 / 失焦 / 挂起 / 断连立即撤权并清理显示 |
| 存储掉电与回滚 | 在加密写、nonce 预留、提交计数和头记录步骤断电；旧密文重放 / 位翻转 / 错长度只能拒绝或保留完整旧快照，不接受未提交内容 |
| 启动 / 更新 / 调试 | 错签名、旧版本、截断更新、复位中断、SWD 重新接入和备用域掉电；不能回到可读取旧秘密的开放模式 |
| 平台互通 | macOS / Linux / Windows 分别实测管理；iPhone / Android 分别测 FIDO 与 NFC 管理 AID，不能用网页支持 FIDO 代替管理 App 验收 |

SE 对象注入、owner PIN 设置和调试关闭应在审计后的受控流程中进行。每台随机 SCP03 密钥、pepper、salt 和私钥分别生成；工厂只能收到公开 schema，不能收到你的真实 PIN / recovery codes。若 PIN 遗失，应使用已经验证的完整销毁 / 重新注册流程，不提供读取旧数据的备用门。

## 8. 抗干扰、硬件攻击与实验室项目

自己能做初筛：USB 插拔 / 开关机、低电量、屏幕全亮、同时按键、手持 / 外壳 NFC、不同 5V 电源和标准充电器、开壳与电池断开；记录电流、轨电压、复位 / SE_EN / LCD 时序及异常恢复。不能自己用高压 ESD 枪或随意短接软包做“安全测试”。

交给实验室的范围：ESD / EFT / 供电扰动 / 辐射与传导，欠压 / 过压 / 时钟 / EM 故障注入，功耗和 EM 侧信道，以及触点桥接、模块替换、总线探针、debug 解锁、备用域丢失和封装侵入。先约定安全供电夹具、仪器带宽、波形 / 轨迹数量、攻击预算、目标操作、判据和复测费用。

FI 的目标不是“还能重启”，而是**不得错误认证、重复 nonce / 计数、绕过 PIN 或确认、泄露旧明文或执行未签名固件**。测监督器响应之外的短脉冲；典型响应时间不能视为覆盖全部攻击。SCA 要同时评估 PIN / pepper / FIDO 私钥路径，做泄漏统计及密钥恢复尝试；TVLA 无显著泄漏不等于无法攻击。

报告必须明确哪些攻击没测、能力限制和剩余风险。先让实验室书面确认个人客户、工程数量、是否接收开源 PCB 和 Rust 固件；现有[境内实验室名单](MAINLAND_SUPPLIERS_AND_LABS.md)仍是候选，不是替你保证承接本项目。

关闭所有 R0.5 [生产门槛](../docs/SECURITY_REVIEW_R05.md)后冻结硬件 / 固件 / 管理器版本，再给 K01 / K02 / K03 分别登记供应批次、板与固件摘要、公开设备身份、配对 / PIN / 调试生命周期检查、充电 / 电池 / NFC / LCD / 十键 / 防拆 / 平台结果。账户分别注册三把，不把一个秘密镜像复制到三把上。

每台都验收，不以第一台通过替代其他两台。恢复码还需要一份独立离线备份。当前尚未到此步骤；生产状态保持 **BLOCKED / physical NOT_RUN**。
