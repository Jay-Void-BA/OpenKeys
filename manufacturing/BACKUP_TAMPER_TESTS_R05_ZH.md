# R05 独立备份、主动防拆与电量采样：实板验收

[制作手册](BUILD_R05_ZH.md) · [电源依据](../docs/CLASSICAL_SE_POWER_R05.md) · [模型](../hardware/r05/review/backup-tamper-model.json) · [Root 存储测试](ROOT_STORAGE_TESTS_R05_ZH.md)

本规程对应独立 CR-2032/HFN、LM66100、三个主动回路触点及 TMUX1511 的 195 位 BOM。
结果全部为 **NOT_RUN**。电路 ERC / DRC、理想脉冲 RC 模型和寄存器模型均不是实板通过记录。
生产 Root 的连续性锚点 / 主动防拆初始化与受控销毁尚未完整接通，诊断镜像不能执行下表所有项目。

先做单独工程样机，使用合成 PIN、SE 密钥、OTP 和 notes。记录提交 SHA、PCB 摘要、
每颗安全芯片及电池批号、焊接 / 外壳版本、仪器校准、原始波形和失败步骤。
破坏性故障测试不要使用三把准备存真实账户的最终设备。

## 接线与仪器

需要有经验的工程人员、限流电源、可安全隔离的 USB 分析夹具、示波器、电子负载、
低负担电压微电流表、电池模拟器和温度测试设备。不要将实验电源与真实软包 / 充电器直接对顶，
不要注入软包裸极；高能 ESD / EMC / FI 交给具备条件的实验室。

测点在 PCB 内部焊盘，成品不增加外部调试接口：

| 信号 | 位置 / 用途 |
|---|---|
| BACKUP_CELL / BACKUP_LIMITED | BT1 正极 / R61 后、U13 VIN；记录电池电流方向 |
| VBAT_BACKUP | U13 VOUT / CE、C41 / C56、U4.1；与 SYS、BAT、主 3.3V 分开 |
| TAMP_DRIVE_RAW / TAMP_DRIVE | PA1 / R63 两端；不得用外部推挽源直接对打 MCU 输出 |
| CASE_TAMP_RETURN | PC13、SW15 返回、R62 上端；高阻节点优先有源高阻探头 |
| TAMP_DIFF / TAMP_DIFF_FILTER | U24.7、R66 / C62 后；与 U25 / U26 输出、NRST 同步采样 |
| BATTERY_DIVIDER / BATTERY_SENSE | U28.3 / U28.4；C61 在隔离前，R68 在 ADC 侧 |
| NRST / SE_EN / LCD_VCC_SW | 验证独立复位、SE 失能和 LCD 锁存切电，不只观察重启日志 |

10MΩ 探头会改变 470k / 1M 偏置，必须计入负载；普通探头引线也会改变主动回路电容。
先测无探头运行，再评估测量本身对电流和故障检测的影响。不要在带秘密的成品上加公开 SCA 触发引脚。

## 验收矩阵

| 编号 | 操作 | 必须记录 / 拒绝条件 |
|---|---|---|
| B01 极性与反灌 | 不接主软包，分别接 / 断 USB、主 3.3V、独立备份；覆盖 SW1 和 USB 热插拔 | BT1 极性、U13 CE=VOUT、未用 ST=GND。不得启用 MCU VBAT 充电。测所有正反向稳态电流及瞬态电荷；取得确切一次电池供应商对允许反向电流的书面限值。资料拿不到或超限，先改隔离电路，不能直接下生产单 |
| B02 连续备份 | USB 与主软包完全断开，只留 BT1；在拟定温度范围连续运行并改变触点 | PA1 仍为真实硬件随机主动输出；记录 LSE、VBAT、电流、开盖标志与备份寄存器保持。实测活跃防拆附加耗流若超过模型分配，重算寿命 / 改板；不得把 nominal225mAh 当可用容量保证 |
| B03 备份丢失 | 已配置合成数据后移除所有能源并放尽备份电容，再恢复 USB | 生产 Root 必须隔离设备并拒绝旧 PIN / 私钥；不得当成工厂空白，自动重建锚点、清标志、播种后恢复旧资料。必须另行完成受控全部销毁才能重新配置 |
| B04 主动触点 | 保持 SW12 闭合，分别断开 SW13 / 14 / 15，再测试返回端固定高 / 低、开路和慢变化 | 同时记录驱动、返回、失配、滤波、NRST、SE_EN 和 LCD。失配应触发真实 TAMP 事件和独立硬复位；记录最短 / 最长延迟及未检出情形。PRNG 连续同值可能延后检测，不能用单次典型波形作最坏界限 |
| B05 独立触点 | 主回路保持正常，单独释放 SW12；复位期间改变 SE_ENABLE_REQUEST 和 LCD_ARM_CLK | NRST 被保持为低，SE_EN 失能，LCD 电源锁存被清除。软件和主机不能压过硬复位；释放后不得自动恢复旧显示或旧 PIN 会话 |
| B06 波形桥接 | 由实验室对触点桥接、外部匹配波形、探针与封装拆开分别评估 | 记录哪些桥接可以绕过检测。当前分散触点不是主动网格，不能把该测试写成“防拆不可绕过”。若攻击预算超出可接受边界，需增加经过评估的封装 / 网格及重新制板 |
| B07 时钟与状态 | 合规夹具扰动 / 停止 LSE、慢升降 VBAT、温度循环；跨任意复位检查真实 TAMP 状态 | 已配置设备不得自动重播种、改滤波、改变输出映射或清事件恢复私密服务；必须可靠识别备份连续性丢失。检查硬件共享输出为 OUT4 / IN1，不能误配 OUT2 或旧 IN3 |
| B08 ADC 断电 | 主电池在允许上限，主 3.3V=0；再覆盖慢 / 快上下电、USB 无电池、保护断开、热插拔与复位 | 测 BATTERY_DIVIDER、ADC 侧、主 3.3V、电流和过冲；复位低时 U28 隔离。模型给 ADC 侧 0.2121V 的分配，不是实测上界；须核实真实漏电 / 温度及 MCU 注入限制，不得因看到“可读电压”而忽略反灌 |
| B09 ADC 精度 | 用已校准表比较不同电池电压 / 温度 / USB 负载，验证 VREFINT 与长采样时间 | 使用带 R68 负载的 100/530 比例及误差；未校准只显示粗略电压 / Charging / Low，不显示虚构精确百分比。没有主电池时不能仅凭 BAT 节点电压判断电池存在 |

## 连续性与销毁的判定

备份寄存器不是不可回滚的全部数据库。Root 还须把连续性锚点与受认证的内部日志、
SE 身份 / 配对和 owner epoch 绑定。仅检查某个固定 magic、仅查看 RTC 是否走时，
或者无条件重设主动防拆配置，都不足以授权私钥。

当前读回约束：PA1 OUT4 / PC13 IN1，ATCR1=`C0030301`、ATCR2=`00000300`，
INITS=1 / SEEDF=0；FLTCR=`80`、CR2 / CR3=0、OR=0、RPCFGR=1。
PWR_BDCR 要求 MONEN=1、BREN=0、VBE=0；预算另计监测缓冲器最大6.5µA。
RTC 使用已稳定且启用 CSS 的 LSE、中低驱动；备份区全32寄存器归 Secure / privileged。
nonce 在 BKP8..15，逐字反码在16..23，`OKB1` 标记及反码在24..25，不占用 BHK0..7。
Root 须将受认证日志当前 owner 交给实际 `Service::verify_backup_owner`，再核对 SE owner；
这个 API 与结构检查不是已完成的生产协调器，不提供工厂空白 / 全清空许可。

防拆导致 DHUK dummy / 日志拒绝后，应保持闭锁。不得为了读回原数据自动清 TAMP 标志。
独立复位和 SE_EN 只是故障互锁；SE 私钥仍必须由原生 PIN ACL、独立协议权限及活动会话共同限制。
必须完成全 SE / NOR / 内部 Root / 配对 / staging 的销毁协调，才能声称“全清空”。

验收表每项有原始证据、失败修复及重复测试，且生产软件与安全初始化齐备后，才讨论
三把最终设备的独立密钥注入。当前没有通过 FIDO / CC / EMVCo 或整机抗侧信道认证。
